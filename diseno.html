Diseño

Elegí cómo querés ver ESLE2. Los cambios se aplican al instante, se guardan en una cookie de este navegador y valen para el IDE, el curso, la documentación y ESLE2 POO. Hay una configuración para el modo claro y otra para el oscuro: estás editando la del claro (cambialo con el botón ☾ / ☀ de arriba).

Color de fondo

Define el fondo de las páginas y de los paneles.

Colores de la sintaxis

Empezá por una paleta lista y, si querés, retocá cada categoría.

Fondo del editor

Algunas paletas traen el suyo. Podés elegir otro o dejar el del fondo general.

Cada categoría

Estas son las categorías que reconoce el resaltado. Tocá un color para cambiarlo.

vista previa

El resaltado distingue el contexto: un nombre después de clase se pinta como clase, uno seguido de ( como función, uno después de un punto como atributo, y los parámetros se separan de las variables. Igual que en Visual Studio Code.
